# Contributing to SHI

SHI is in directed pre-alpha development. Small, evidence-backed issues and pull requests are welcome; large narrative, engine, or art changes require an agreed design brief first.

1. Read `AGENTS.md`, the game design document, and the relevant history/art/localization policy.
2. Do not add private books, source scans, chats, credentials, generated caches, or unreviewed AI assets.
3. Keep campaign truth in `content/`; sync it rather than editing client copies.
4. Add source classification and uncertainty for historical content.
5. Run `npm install`, `npm run validate`, and `npm run build`.
6. Include visual evidence for layout changes and provenance for assets.
7. Use a focused imperative commit message.

By contributing, you affirm that you have the right to submit the material. No contribution changes the repository license or ownership terms unless accepted in writing.
