# Mobile identity

`shi-icon-1024.png` is a raster export of the existing project-original
`assets/favicon.svg` seal, using the workstation's CJK serif fallback. It is not
a generated external image or a third-party character. Intended use: iOS/Android
launcher icons and store identity. License: project-original (repository terms).
Review: inspected 2026-09-26; legible traditional 勢 character, opaque red field,
gold frame, correct square sizing. Earlier missing-glyph exports were rejected
and replaced, not shipped. The reproducible renderer outlines Noto Serif CJK SC
(SIL OFL-1.1) before rasterization; no missing-font dependency in packaged icons.

The iOS title reuses the already reviewed `assets/art/keyart/daze-village-rain-v1.png`;
its existing provenance and review record remain authoritative. Native SceneKit
terrain and tokens are project-authored code, explicitly schematic, not a claim
of lifelike animation or historical surveying.
