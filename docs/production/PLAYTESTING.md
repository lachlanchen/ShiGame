# Visible web playtesting

SHI browser QA uses a dedicated localhost-only Xvfb/noVNC/Chrome profile so tests can be watched and reproduced without touching the user's normal browser.

## Dedicated endpoints

| Service | Endpoint |
| --- | --- |
| Web preview | `127.0.0.1:4173` |
| X display | `:121` |
| VNC | `127.0.0.1:5921` |

| Chrome DevTools | `127.0.0.1:9321` |

All bind to loopback. The reusable Chrome profile lives under ignored `.runtime/novnc/profile`.

## Gate command

```bash
npm run build
SHI_X_DISPLAY=:121 SHI_CDP_PORT=9321 SHI_TESTED_COMMIT="$(git rev-parse HEAD)" node scripts/playtest-web.mjs
```

`SHI_TESTED_COMMIT` is intentionally explicit: the harness will otherwise label the report `working-tree` rather than infer traceability. Supply it only when the served build actually corresponds to that commit.

npm run render:audio-reference
