# SHI：本地制作的可玩历史电影

2026-09-26 · 制作方向与首轮试作；不是完成品或发行许可。

## 玩家应该得到什么

人在历史压力里做选择，而不是读完一段年表后回答一道题。
先让玩家认识具体的人，理解他们想保住什么，再给出无法兼得的选择。
电影的表演、音乐、声音和留白让代价可感；游戏的规则让选择有后果。
“创业启发”来自对信任、信息、组织、资源和时机的亲身体会，不来自
古人替现代作者宣讲成功学。失败也要有可理解的过程和继续思考的价值。

长线愿景是以《资治通鉴》为主干的分期历史作品，随后可以研究德川家康
等独立篇章。现有大泽乡篇用于证明制作方法，不等于把全书缩成秦末，
也不是承诺一次制作整部通史。春秋前史需另建来源边界，不能全称为
《通鉴》正文；该书开篇为周威烈王二十三年，可参照
[中华书局原文书页](https://www.chunghwabook.com.hk/upload/files/2025/05_19/1332aefce1bddd19380911a73410a7cc.pdf)。
未来德川篇应从独立史料和原创戏剧建构出发，不复制现代小说、影视剧
的独有对白、造型或表演。所有重构继续遵守现有历史来源政策。

两张 24 GiB 卡不是一个透明的 48 GiB 显存池。视频的 offload、参考片数量、
时长和分辨率应遵循实际实现；不能因空闲就同时启动模型、Unreal 和 Blender。
本地生成不花云端生成点数，但仍消耗电力、存储、时间和人工审片。

## 从定妆到游戏

故事与决策 → 角色定妆 → 镜头首帧 → 短镜头候选 → 连贯性审核 → 游戏内整合。
音乐可在同一个已锁定戏剧问题下独立试作；没有通过定妆的角色不进入视频量产。

1. **人物先行。** 沿用 canonical character ID。每人建立独立的正面、
   三分之四、侧面、全身、表情与光照参考；记录图像哈希、衣着版本及审核人。
   具体交付见 [定妆研究](../art/DAZE_CHARACTER_IDENTITY_STUDY.md)。
2. **锁定不是复制提示词。** 身份图决定脸，场景图决定空间，姿态/运动参考
   决定动作；每张参考只承担明确职责。seed 用于复现，不等于身份保证。
   原始定妆图始终是身份锚点，不能只用上一个生成镜头滚动继承，累积变脸。
3. **先审静帧再动起来。** 先确认人数、衣装、道具位置和目光方向，再生成
   短片；将起始、中间、末尾及关键接触帧并列检查。不同人物不能共用脸，
   左右手、伤痕、湿衣、持物状态不能在反打或切镜后无故交换。
4. **关键动作可控。** 持物交接、近身交战、玩家可改变的动作优先由可编辑
   Blender/Unreal 表演负责；生成视频用于经过审核的背景、过场或预演。
   当前 Gate 5B 的 30 fps/421 样本与 H3 的 24 fps 视频不是同一个合同，
   不能把后者改个播放速度就当作准确的物理交接。
5. **配乐服务选择。** 固定角色/主题动机，再做紧张、犹疑和余波的编配；
   优先制作可编辑分轨和过渡，不把分别生成的三首曲子假装成相位对齐分轨。
   保留静默，声音不能替代文字与视觉中的关键游戏信息。
6. **游戏保持主动。** 引擎处理探索、视角、决策、战斗规则、存档与可重复
   结果；预渲染镜头不修改这些状态。视频不能把游戏变成只能等待的播放列表。
   所有过场保留暂停、跳过、字幕和 reduced-motion 路径。

## 首个制作样片：雨夜中的承诺

先沿用当前大泽乡的真实节点和选择，不增写一套平行剧情。目标是让已有
约一个短章节的决策链更有人物感，而不是先铺满全部朝代。

| 现有节点 | 戏剧任务 | 玩家必须看见的东西 |
| --- | --- | --- |
| rain-order | 名籍不是一串数字，决定关系到眼前的人 | 掌简人仍拥有未决选择；不把任何开局分支拍成标准答案 |
| open/fire/shadow-council | 不同开局走向不同人物关系和组织办法 | 保留三个既有分支；人物反应与实际状态一致 |
| broken-crossing | 先前承诺遇到地形、时间与运输代价 | 先救人、修渡口、弃车等现有计划可理解且有取舍 |
| three-roads | 同样离开雨夜，却形成不同的队伍 | 结局回应前面的行动，不用旁白宣布玩家“懂得创业” |

第一个审美试验只关注陈胜与掌简人的定妆、雨中停顿和未决关系。
现有湿名籍转手合同、历史疑点、禁用特写与人类审核门槛全部保留。
镜头候选和原创音乐试作不得自动接入正在审核的 iOS/Android 1.0.0。

## 本轮交付与下一步

本轮保存硬件/服务检查、一个六 seed 的短纯音乐试作和音频检查记录到
ignored private runtime。配乐是 audition，不是正式主题曲或已验收游戏资产。
六个 45 秒原始 WAV 均通过完整解码与信号健康检查；另有固定增益的等响度
试听副本与本地试听页。人声误生、旋律、情绪及文化/相似性审核尚未完成。
生成进程已退出，GPU 使用量回到预检基线；没有常驻播放器或新服务。
没有新角色图片、合格电影镜头、视频模型安装或正式游戏整合的完成声明。

下一步最小交付：一名角色的候选定妆板 → 用户选定身份方向 → 一个短镜头
的身份/身体/光照审核 → 同角色反打 → 原有选择与后果的可玩整合。
另一个角色、另一种光线和一次反打也能成立后，才扩大量产。
