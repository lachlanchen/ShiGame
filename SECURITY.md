# Security policy

Do not open a public issue for a vulnerability that could expose private material, credentials, saves, or players. Report it privately through GitHub's security advisory feature for this repository.

The project currently has no accounts, server, analytics, payments, or cloud saves. Browser saves stay in local storage. Private research and browser profiles are excluded from Git.

Supported security updates apply to the latest `main` pre-alpha only. Never include real secrets or private source extracts in a report.
